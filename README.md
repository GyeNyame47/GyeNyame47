## Featured project

### [Enterprise Network: HQ and Branch](https://github.com/<GyenNyame47>/ccna-enterprise-network)

A two-site enterprise network designed, built and tested in Cisco Packet Tracer, with sanitized configs, test evidence and a troubleshooting log.

| Area | What I built |
|---|---|
| Design | VLSM plan from 10.10.0.0/16, per-site blocks, /30 routed links |
| Switching | VLANs and trunking, Rapid PVST+, LACP EtherChannel, port security, BPDU guard |
| Routing | Single-area OSPF with MD5 authentication and passive interfaces |
| Redundancy | HSRP with preemption and uplink tracking, tested through a core failure |
| Services | Central DHCP relay, DNS, NAT/PAT to a simulated ISP |
| Security | Guest isolation ACL, management ACL, SSH only, WPA2 guest wireless |
| Documentation | Test results with screenshots, a troubleshooting log and honest limitations |
